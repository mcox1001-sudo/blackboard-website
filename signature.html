How to install in Gmail

  1. Click Copy as rich text (recommended) above.
  2. Open Gmail → cog icon → See all settings → General.
  3. Scroll to Signature → Create new, name it BLACKBOARD.
  4. Click into the editor and paste (Cmd/Ctrl + V).
  5. Set the new signature as default for new emails and replies, then Save changes at the bottom.
How to install in Outlook (web)
  1. Click Copy as rich text (recommended).
  2. Open Outlook → settings cog → Mail → Compose and reply.
  3. Under Email signature, paste into the editor.
  4. Tick the auto include options for new messages and replies, then Save.
How to install in Outlook (desktop, Windows)
  1. Click Copy signature HTML above.
  2. In Outlook, File → Options → Mail → Signatures → New.
  3. The classic signature editor doesn't take HTML, so on Windows save the HTML to %APPDATA%\Microsoft\Signatures\BLACKBOARD.htm with your details, then close and reopen Outlook and select it.
How to install in Apple Mail
  1. Click Copy as rich text (recommended).
  2. Mail → Settings → Signatures → +.
  3. Untick Always match my default message font, then paste.
Heads up: Outlook desktop on Windows uses Word to render signatures and won't show the SVG social icons. Everything else (Gmail, Outlook web, Apple Mail, Outlook iOS/Android, Gmail iOS/Android) renders the icons fine.
