01

Gmail

Hit Copy HTML. In Gmail go to Settings → See all settings → Signature. Click Create new or your existing signature, then paste. Save changes at the bottom.

02

Outlook

Hit Copy HTML. In Outlook go to Settings → Mail → Compose and reply. Paste into the signature box. Tick the boxes to apply to new and reply emails. Save.

03

Apple Mail

Use Download .html. Open the file in Safari, select all, copy. In Mail go to Settings → Signatures, create a new one, paste. Untick "Always match my default font".
